# 山東德縣衛氏博濟醫院報告書

1930 年山東德縣衛氏博濟醫院院務報告，收院史與設備、董事會簡章、門診和住院章程、護士學校章則、收支與就診統計及卷末職員名錄。本版在名錄初錄 v0.1.0 上補入其餘來源影像。

This 1930 lithographed annual report documents the organization, inpatient and outpatient administration, nursing school, financial and patient statistics, and staff roster of the Williams-Porter Hospital in Dezhou, Shandong.
